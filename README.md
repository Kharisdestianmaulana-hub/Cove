# Cove

A quiet, native macOS camera app built with SwiftUI, AVFoundation, Core Image, Metal, and Vision.

## Features
- **Live Metal Preview:** Smooth 30fps hardware-accelerated preview with real-time Looks and color adjustments.
- **Photo & Video Capture:** Countdown timer, burst mode, aspect ratio framing, horizontal mirror, and internal/external microphone selection.
- **Video Teleprompter:** Draggable, resizable, word-by-word highlighting with `A-`/`A+` font sizing, WPM presets, and Auto-Stop delay.
- **Virtual Video Background:** Real-time person segmentation supporting Blur, Green Screen, and custom background images.
- **Integrated Gallery:** Non-destructive photo/video editing, filmstrip navigation, Trash support, and native `AVPlayerView` playback.
